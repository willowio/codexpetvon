# A King Von pet for your Codex. Don't ask why.

![Von in Codex](assets/codexpetvon.png)

## install

Give Codex this repo's link and ask it to install Von.

Or download the repo and run the command for your system:

**macOS**
```bash
bash install.sh
```

**Linux**
```bash
bash install-linux.sh
```

**Windows (PowerShell)**
```powershell
.\install.ps1
```

Then simply select him in Pets.

*Windows and Linux haven't been fully tested cuz I'm on a Mac.*
